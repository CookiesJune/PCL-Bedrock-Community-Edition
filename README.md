# PCL-BCE（Plain Craft Launcher Bedrock Community Edition）

![Platform](https://img.shields.io/badge/平台-Windows%20x64-lightgrey)
![Release](https://img.shields.io/github/v/release/CookiesJune/PCL-Bedrock-Community-Edition)
![License](https://img.shields.io/badge/License-Apache--2.0-orange)

> 基于 [PCL-Community-Edition](https://github.com/PCL-Community/PCL-CE) 二次开发的社区版 Minecraft 启动器。

为联机场景优化的 PCL-CE BE改版，内置异地组网工具，开箱即用

---

## ✨ 功能特性

- 内置 GravityCone / EasyTier 异地联机组网，无需额外配置
- 基本全面支持Bedrock，包括启动、下载资源、版本管理
- 保持最新正式版PCL-CE内核

## 📥 下载

前往 **[Releases 页面](https://github.com/CookiesJune/PCL-Bedrock-Community-Edition/releases)** 或 **[官网](https://pcl-bce.netlify.app/)**下载最新版本。

| 文件 | 说明 |
| --- | --- |
| `PCL-BCE_v1.1.0_x64.zip` | 推荐，压缩包（约 18 MB） |
| `PCL-BCE_x64_v1.1.0.exe` | 单文件exe版（约 50 MB）  |

> 💡 如果杀毒软件报毒：本程序为未签名的第三方社区工具，请将程序加入信任区后再运行（下载前建议核对文件哈希，防止下载被篡改）。

## 🚀 使用说明

1. 下载 `zip` 并解压，或直接运行 `exe`。
2.使用方法与PCLCE大致相同

**系统要求**：Windows 10/11 x64。
